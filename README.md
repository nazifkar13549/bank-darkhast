# بانک درخواست

اپ وب (PWA) برای جستجو و پیگیری تقاضاهای تدارکات؛ کاملاً آفلاین‌پذیر و میزبانی‌شده روی GitHub Pages.

## راه‌اندازی
1. یک مخزن جدید در GitHub بسازید (مثلاً `bank-darkhast`).
2. همهٔ فایل‌های این پوشه (از جمله پوشهٔ `.github`) را در شاخهٔ `main` آپلود کنید.
3. در مخزن: **Settings → Pages → Source = GitHub Actions**.
4. چند دقیقه بعد آدرس اپ: `https://USERNAME.github.io/REPO/`

## به‌روزرسانی داده
- فایل `data.json` را عوض کنید (فیلد `version` باید بزرگ‌تر شود) و commit کنید؛ اپ خودکار به‌روز می‌شود.
- یا داخل خود اپ از ⚙ فایل اکسل جدید را انتخاب کنید (فقط روی همان دستگاه ذخیره می‌شود).
- پس از تغییر فایل‌های برنامه، عدد `V` در `sw.js` را زیاد کنید.
